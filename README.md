# obix-core-oop

> Previous name: `@obinexusltd/obix-core-oop` — OBIX packages are named without an npm scope since decision D-102 (2026-09-29); the package, its version and its exports are unchanged.

**The OOP projection — a generated class.**

```bash
npm install obix-core-oop
```

## API

```ts
const Timer = toOOP(artifact);
const t = new Timer({ props: { limitSeconds: 5 } });
t.Start();          // generated method -> dispatch("Start") -> applyAction(...)
t.Tick();
t.state;            // read-only; assigning throws
t.props;            // frozen
t.finished;         // generated derived getter
t.render(); t.validate();
```

`state` and `props` are `#private`. `props` is frozen. Assigning `state` throws.
Every generated `Start` / `Tick` / … method delegates to `dispatch`, which calls
`obix-core-ir.applyAction`. There is never a second implementation of an action.

## Dependency role

`obix-core-spec` + `obix-core-ir`. Consumed by `obix-compiler-equivalence` and `obix-fixture-timer`.
